## 📋Tribute Page - Dr. APJ Abdul Kalam

A beautifully designed tribute page dedicated to Dr. APJ Abdul Kalam, the Missile Man of India and the 11th President of India.


## 🎯 Objective

To create an appealing and informative tribute page using HTML and CSS that:
- Highlights the life and achievements of Dr. APJ Abdul Kalam
- Demonstrates understanding of HTML structure and CSS styling
- Provides a responsive and visually appealing layout
- Showcases effective use of typography, colors, and spacing

## ✨ Features

- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **Modern UI**: Clean and professional design with gradient backgrounds
- **Interactive Elements**: Hover effects on cards and links
- **Well-Organized Content**: 
  - Biography section
  - Major achievements with icons
  - Inspiring quotes
  - Personal admiration section
  - Legacy highlights
- **Custom Styling**: 
  - Google Fonts (Poppins & Playfair Display)
  - Gradient color schemes
  - Smooth animations
  - Professional card layouts

  ## 🛠️ Technologies Used

- **HTML5**: Semantic markup for content structure
- **CSS3**: Advanced styling including:
  - Flexbox and Grid layouts
  - CSS Gradients
  - Transitions and transforms
  - Media queries for responsiveness
- **Google Fonts**: Custom typography
