## Basic Web Calculator

A modern, interactive calculator built using HTML, CSS, and JavaScript with support for both basic and advanced mathematical operations.


🔹 Features
- Basic operations: Addition, Subtraction, Multiplication, Division
- Brackets ( )
- Square Root (√)
- Modulo (%)
- Decimal point (.)
- Plus/Minus (±)
- Answer memory (ans)
- Delete (del) and Clear
- Interactive UI with CSS Grid
- ENTER button for calculation

🔹 Technologies Used
- HTML
- CSS
- JavaScript
